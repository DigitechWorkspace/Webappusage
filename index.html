What is the use EduDocs?

The use of EduDocs is to help student to create research document without creating an account.

Can a student save file on their storage?

No, EduDocs Requires the document to be printed after finishing it, so student cannot simply save document in their files.

Is EduDocs Free?

Yes, Students can use EduDocs for free, but EduDocs has limitations, it can save file on phone and other device storage.
